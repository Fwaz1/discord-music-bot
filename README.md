# بوت ديسكورد للأغاني

## التشغيل

1. ثبّت Node.js (النسخة 18 أو أحدث) من nodejs.org
2. افتح الترمنال داخل مجلد البوت واكتب:
   ```
   npm install
   ```
3. انسخ `.env.example` وسمّه `.env`، وحط فيه التوكن والاسم.
4. حط الصورة اللي تبغاها بنفس المجلد باسم `avatar.png`، وخلّ `UPDATE_AVATAR=true` لأول تشغيل بس.
5. شغّله:
   ```
   npm start
   ```

## الأوامر

`/play` `/skip` `/pause` `/resume` `/stop` `/queue` `/nowplaying` `/volume` `/loop`

## ملاحظات

- التشغيل من يوتيوب (بالاسم أو الرابط) عن طريق yt-dlp، ومن SoundCloud، ومن روابط الصوت المباشرة.
- يوتيوب يخالف شروطهم، فاستخدمه لسيرفرك الشخصي ولا تنشر البوت للعامة.
- إذا وقف يوتيوب فجأة فغالباً yt-dlp يحتاج تحديث: شغّل `npm update @distube/yt-dlp` ثم أعد تشغيل البوت.
- إذا شغلت البوت على استضافة (VPS) ممكن يوتيوب يطلب تسجيل دخول، وساعتها شغّله من جهازك أو استخدم كوكيز.
- ديسكورد يحدد عدد مرات تغيير اسم البوت (مرتين تقريباً بالساعة)، فلا تكثر.
- لا تنشر ملف `.env` أبداً.
